**Tanggal:** 2026-09-13 · **Status:** Dalam eksekusi

## 2. Definisi Production 100% (10 gate)

1. Build reproducible & image ter-pin (bukan dev server).
2. Semua test hijau + coverage threshold + static analysis.
3. Auth & data isolation terverifikasi (unit + E2E + security).
4. Security headers, TLS, secrets terkelola, scanning otomatis di CI.
5. Migrasi sebagai release step (`migrate --force`), bukan `migrate:fresh`.
6. Backup otomatis + offsite + restore drill teruji.
7. Observability: error tracking, log terstruktur, metrics, uptime, alert.
8. Runbook deploy/rollback/incident + staging env.
9. UI lulus a11y & responsif di viewport target.
10. Dokumentasi operasional diperbarui.

## 4b. Progres eksekusi (2026-09-13)

**M0 selesai:**
- Plan dokumen ini tersimpan.
- `.gitignore`: abaikan `skill/`, `infra/backups/`, `*.sql.gz`, `.commandcode/`, `vendor/`.
- Root `package.json` (engines + script terpadu `dev/build/lint/test/typecheck`).
- `.dockerignore` untuk `apps/api` & `apps/web`.
- Belum: `git init` + commit pertama (menunggu konfirmasi).

**M1 selesai:**
- `/settings` dibatasi `owner, manager` (nav item + path rule) — hilangnya 403 lintas-mode.
- `(dashboard)/layout.tsx`: `.catch()` + redirect + listener event 401 global.
- Halaman baru: `not-found.tsx`, `error.tsx`, `global-error.tsx`, `loading.tsx`.
- `HttpClient`: dispatch `laundryos:unauthorized` pada 401.
- Semua list page menampilkan `ApiError.message` nyata (bukan teks generik).
- Backend: `RateLimiter::for('api')` 60/menit + `throttleApi()`; API.md dikoreksi.
- Paritas mock↔Laravel: tolak overpayment, tolak jadwal lampau (+ validasi UI), `cashBalance` dihitung dari kas, default laporan 30 hari, CSV dengan tanggal-waktu, notifikasi order digenerate.
- `phpunit.xml` dibuat hermetis (`<server>` menang atas env container) → test tak lagi bergantung Mailpit/Redis.

**Bukti verifikasi M1:**
- Backend: `php artisan test` **109 passed (363 assertions)**; `pint --test` **PASS 143 files**.
- Frontend: `tsc --noEmit` 0 error; `eslint src` 0 error; `vitest run` **41 passed**; `next build` exit 0.
- E2E Playwright (mock) **16 passed**.

**M2 selesai (auth httpOnly cookie Sanctum SPA):**
- `AuthController`: login mendeteksi frontend stateful (`EnsureFrontendRequestsAreStateful::fromFrontend`) → set cookie sesi, balas `{user}` tanpa token; non-browser tetap dapat `{token,user}`. Logout menghancurkan sesi + revoke token.
- `LoginRequest.device_name` jadi opsional; CORS `supports_credentials=true`; `.env.example` + `SANCTUM_STATEFUL_DOMAINS`/`FRONTEND_URL`; API.md diperbarui.
- Web: `HttpClient` pakai `credentials:"include"` + `X-XSRF-TOKEN` + `csrf()` ke `/sanctum/csrf-cookie`; token dihapus dari `sessionStorage`, sesi pakai `localStorage` (cookie httpOnly menyimpan otentikasi).
- Test backend baru: `test_login_dari_spa_memakai_sesi_tanpa_token`.

**R1 (OOP) — refactor logic layer:**
- `TaskMachine` (dari fungsi lepas di komponen), `PaymentPolicy` (label/status/validasi draft), `ApiClientFactory`, `SessionManager.storage()` private; helper `Format` (todayIso/isoDaysAgo/initials/greeting/duration). Rules resmi di `AGENTS.md`.

**Bukti verifikasi M2:**

- Frontend: `tsc` 0, `eslint` 0, `vitest` **40 passed**, `next build` exit 0, E2E **16 passed**.

- Mitigasi: TDD + E2E mode Laravel nyata sejak M1, staging sebelum prod, subagent paralel per app.
