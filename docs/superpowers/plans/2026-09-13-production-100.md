# Plan — LaundryOS Production 100%

**Tanggal:** 2026-09-13 · **Status:** Dalam eksekusi
**Scope disetujui:** `apps/api` + `apps/web` + `apps/mobile` (Flutter) + `apps/site` (Astro)
**Deploy:** VPS self-hosted, Docker Compose + TLS
**Keputusan auth:** pindah dari bearer `sessionStorage` ke **httpOnly cookie Sanctum SPA**
**Fitur eksternal** (payment gateway, WhatsApp, printer thermal, WAF/CDN, pen-test eksternal): **pending**, dikerjakan setelah local 100% — lihat §5.

## 1. Kondisi awal (audit 2026-09-13)

- API Laravel 13: 43 route terimplementasi, 109 test, RBAC + policies + tenant global scope fail-closed.
- Web Next 16: 13 halaman, mock + Laravel client, 41 unit test, 16 E2E (mock only).
- Gap utama: runtime API dev-only, storage proof 404, auth token di sessionStorage, tanpa global rate limit, index FK minim, tanpa observability/CI security scanning, `apps/mobile` & `apps/site` belum ada.

## 2. Definisi Production 100% (10 gate)

1. Build reproducible & image ter-pin (bukan dev server).
2. Semua test hijau + coverage threshold + static analysis.
3. Auth & data isolation terverifikasi (unit + E2E + security).
4. Security headers, TLS, secrets terkelola, scanning otomatis di CI.
5. Migrasi sebagai release step (`migrate --force`), bukan `migrate:fresh`.
6. Backup otomatis + offsite + restore drill teruji.
7. Observability: error tracking, log terstruktur, metrics, uptime, alert.
8. Runbook deploy/rollback/incident + staging env.
9. UI lulus a11y & responsif di viewport target.
10. Dokumentasi operasional diperbarui.
