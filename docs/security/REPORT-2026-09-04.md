# Laporan Security Testing — LaundryOS

**Tanggal:** 2026-09-04 · **Edisi acuan:** OWASP Top 10:2025 + OWASP API Security Top 10:2023
**Scope:** `apps/api` (Laravel 13), `apps/web/src`, image `infra-api`, runtime Docker dev.
**Metode:** abuse-case tests (TDD), Semgrep (gagal environment — diganti audit pola manual), Trivy, probe DAST live, `composer audit` + `pnpm audit`.

## Ringkasan eksekutif

7 temuan, **semuanya sudah diremediasi dan diverifikasi ulang**. Tidak ada temuan kritis tersisa yang reachable.
Skor akhir: backend suite 100+ hijau, DAST live 7/7, audit dependensi bersih, Trivy tersisa hanya CVE tak-terjangkau.

## Yang terbukti AMAN (negatif test)

- Mass assignment (`status/ticket/total/tenant_id` injeksi → diabaikan, server-side semua).
- Upload `.php` → 422; SQLi di `q` → 200/0-baris; IDOR lintas-tenant → 404 (suite).
- CORS origin jahat tanpa ACAO; method salah 405; token sampah 401; body 10MB tanpa 500.
- XSS tersimpan mentah (by design) — output di-encode React (`dangerouslySetInnerHTML` nihil, grep).
- `composer audit` + `pnpm audit`: bersih. `.env` gitignored; tanpa secret di kode (grep).
- Semua endpoint mutasi bergate auth+policy (terakhir: outlet list/show dikunci + test).

## Tidak dinilai (jujur)

- Strix autonomous & ZAP: butuh LLM key/biaya eksternal — diganti tool di atas.
- Semgrep: registry stall 2x19 menit di network ini (image 1.56GB terpull, 0 hasil) — diganti audit pola manual + Trivy.
- A09 logging pipeline, enkripsi at-rest, WAF/CDN, pen-test manusia: di luar MVP.
- Token abilities Sanctum = metadata (enforcement di policies) — keputusan sadar.

## Artefak

- Test: `AbuseTest` (5), throttle login, guest-tanpa-JSON, id-non-numerik, per_page cap.
- Bukti live: sweep CRUD 45/45, sweep DAST 7/7 (skrip dihapus setelah hijau).
